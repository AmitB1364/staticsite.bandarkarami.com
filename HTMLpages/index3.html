AWS S3 Static Website Hosting

Hosted on Amazon S3 with CloudFront CDN and SSL Certificate

Architecture Diagram

Services Used

Service Purpose
Amazon S3 Store Static Website Files
CloudFront Global CDN Delivery
Route 53 DNS Management
ACM SSL/TLS Certificate
IAM Access Control

Implementation Steps

  1. Create an S3 Bucket named staticsite.bandarkarami.com.
  2. Upload website files (index.html, css, images).
  3. Enable Static Website Hosting.
  4. Configure Bucket Policy for public access.
  5. Create SSL Certificate using AWS Certificate Manager (ACM).
  6. Create CloudFront Distribution.
  7. Associate ACM Certificate with CloudFront.
  8. Configure Route 53 records.
  9. Access website using HTTPS.
